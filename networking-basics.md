# Networking Basics

Notes from my Cisco Networking and NVIDIA Intro to Networking certs.

## What is a subnet?
A subnet is a smaller network carved out of a larger network. It helps
organize devices into groups and controls how traffic moves between them,
which improves both performance and security.

## What does a router do?
A router connects different networks together and decides the best path
for data to travel between them, based on IP addresses.
